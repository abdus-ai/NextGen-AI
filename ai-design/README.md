# NextGen AI UI Design Prototype

This folder contains a separate visual design reference and a static HTML/CSS prototype for the six AI workspace pages.

## Pages
- `index.html` — AI Control Room
- `assistant.html` — AI Assistant
- `image-studio.html` — AI Image Studio
- `video-studio.html` — AI Video Studio
- `voice-studio.html` — AI Voice Studio
- `model-center.html` — AI Model Center

## Shared assets
- `ai-studio.css` — responsive dark-navy / cyan-glow design system
- `ai-studio.js` — small demo-only interaction layer

## Important status
This is a front-end UI prototype only. AI providers, Supabase data, file storage, billing/credits, real generation, publishing and authentication are not connected. Buttons show clear prototype notices rather than pretending to run AI tasks. The existing main app and Master Design v32 files are not modified by this branch.

The generated six-screen concept image is a visual reference; this HTML prototype is the separate implementation artifact.
